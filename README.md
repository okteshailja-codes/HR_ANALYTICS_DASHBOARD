# HR Analytics Dashboard – Power BI

##  Project Overview

An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee workforce, attrition, demographics, and key HR trends.

##  Objectives

- Analyze employee attrition
- Identify high-attrition departments and job roles
- Analyze employee demographics
- Understand overtime and job satisfaction patterns
- Provide data-driven HR recommendations

##  Key KPIs

- Total Employees: **1,470**
- Attrition Count: **237**
- Attrition Rate: **16.12%**
- Active Employees: **1,233**
- Average Monthly Income: **6,503**

##  Key Insights

- Sales has the highest attrition rate at **20.63%**
- R&D has the highest attrition count with **133 employees**
- Employees working overtime show higher attrition
- Laboratory Technicians and Sales Executives have high attrition counts

##  Tools Used

- Power BI
- Power Query
- DAX
- Excel

##  Dashboard Pages

1. HR Workforce Overview
2. Employee Demographics & Workforce Analysis
3. Employee Attrition Analysis
4. HR Insights & Recommendations
